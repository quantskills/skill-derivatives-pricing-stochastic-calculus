# 优化说明（v1 → v2）

本次优化围绕该 Skill 的核心承诺——**"把数字算对、并且证明它对"**——修复其"证明"环节的若干漏洞，并补齐宣传过但脚本未实现的能力。所有改动均已用脚本回归验证（见文末测试矩阵）。

## 一、修复的实质问题

### 1. 摘要里的"一致/通过/收敛"是硬编码 → 改为依校验结果动态生成（最严重）
v1 的 `write_report` 把"三法一致""应≈0，已通过""已收敛"写成固定字符串，**不随 `flags` 状态变化**。后果：当某项校验失败、第 8 章给出 🔴 高 时，第 1 章摘要仍会写"三法一致、已通过"，报告自相矛盾。

复现（v1，深度价外 + 近到期 `K=200, T=0.01`）：
```
最高风险等级 🔴 高    ←  第8章
…三种方法互相印证…    ←  第1章（仍写"一致"）
…（应≈0，已通过）…    ←  第1章
```
v2：摘要文案由 `diag["cross_method_ok"]` / `parity_ok` / `converged` 驱动，校验失败时改写为"三法存在偏差，疑似实现/输入问题（见第 8 章）"等。已单测验证文案会随诊断翻转。

### 2. 看跌看涨平价是同义反复 → 改用独立的欧式二叉树 call/put 价
v1 用同一 BSM 闭式解的 `call − put` 算平价残差。由于 `N(x)+N(−x)≡1`，残差**在数学上恒等于 0**，无论 d1/d2 是否写错——这个"已通过"证明不了任何实现正确性。
v2 改用**独立实现的欧式二叉树** call 与 put 价计算残差，配合"树价 vs 解析价"的跨方法检查，平价校验才真正具备发现 bug 的能力。

### 3. 美式期权 headline 取错价格 → 改用美式二叉树价
v1 第 1 章"理论价格"和占比 `pct` 都用 `ana`（**欧式** BSM 价），对美式期权会按整个提前行权溢价低估其价值，并把欧式 MC 与美式树价混在第 5 章同一张表里。

复现（README 主打用例 `put S=50 K=55 T=0.5 σ=0.3 美式`）：
| | v1 headline | v2 headline | 真实美式价 |
|---|---|---|---|
| 理论价格 | 6.80（欧式 BSM）❌ | **6.94（美式树）✅** | 6.9361 |

v2：headline = 美式树价；第 5 章明确标注 MC 为"欧式锚点"、不含提前行权；欧式三法互证与美式价分开陈述。

### 4. 近零价格的假阳性高风险旗 → 引入绝对容差
v1 的跨方法检查只用相对容差，深度价外/近到期时价格≈0，浮点噪声会让解析价落在 `[0,0]` 的 MC 区间外，误报 🔴 高。
v2：跨方法与平价检查改用 `max(相对容差, 绝对容差)`。同一退化用例从误报 🔴 高 纠正为合理的 🟡 中（到期极短）。

### 5. 收敛/隐含波动率状态如实判断
- v1 第 5 章无条件写"已收敛"。v2 实际比较 `N/2 → N` 变化，超容差则写"未完全收敛，建议增大 N"并报中风险。
- v1 隐含波动率仅返回数值或 None。v2 返回状态 `ok / below_intrinsic / above_bound / no_converge / boundary`，触边界单独报高风险（疑似越界报价）。

## 二、补齐的能力

### 6. 波动率微笑/偏斜（此前 README/SKILL 宣传但脚本未实现）
新增 `--strikes` 与 `--market-prices`：对多个行权价逐一反解 IV，第 7 章输出"行权 × 货币度 × 市场价 × IV × 状态"表，IV 极差超 5 vol点 时报"明显波动率偏斜"中风险。

示例（`S=100 T=1`，五个行权）：
```
K=80 IV=0.2664 | K=90 IV=0.2446 | K=100 IV=0.2022 | K=110 IV=0.1976 | K=120 IV=0.2041
IV 极差 = 6.88 vol点 → 🟡 明显波动率偏斜
```

### 7. 报告不再写死 N 与路径数
`--steps`（默认 500）与 `--paths`（默认 200000）现在贯穿计算与报告文字，改参数报告同步变化。

## 三、未改动（刻意保留）

- BSM 价、希腊字母及其口径（vega/100、rho/100、theta/365）经核对全部正确，未改。
- MC 固定 `seed=1`，保持可复现；美式 MC（Longstaff–Schwartz）未实现，美式价以二叉树为准并在报告中说明，以免引入未充分测试的代码。

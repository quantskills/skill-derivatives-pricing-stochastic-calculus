# Derivatives Pricing & Stochastic Calculus

This reproducible Agent Skill covers derivatives pricing, Greeks, implied-volatility inversion, and model-risk validation. It cross-checks Black-Scholes-Merton, binomial-tree, and Monte Carlo methods, including standard errors, put-call parity, and no-arbitrage bounds.

Read [`SKILL.md`](SKILL.md) for the workflow. Install `numpy` and `scipy`, then run `scripts/run_pricing.py` for offline calculations. The tool does not provide market data, trading signals, or investment advice.

Runtime entrypoints: Codex / Claude Code (`SKILL.md`), Cursor (`agents/cursor-rule.mdc`), Hermes / OpenClaw (`agents/portable-loader.md`). Licensed under GPL-3.0-only; see [`LICENSE`](LICENSE).
